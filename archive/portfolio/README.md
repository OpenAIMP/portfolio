# Portfolio

A clean, responsive portfolio starter site built with HTML and CSS.

## Quick Start

1. Clone this repo
2. Push to your GitHub repository
3. Enable GitHub Pages in repo Settings → Pages
4. Set custom domain to `portfolio.openaimp.com`

## Customization

- Edit `index.html` to update your name, bio, and projects
- Edit `style.css` to change colors, fonts, and layout
- The primary color is `#4f46e5` — search and replace to rebrand

## Deployment Options

- **GitHub Pages:** Free, serves static files directly
- **Cloudflare Pages:** Connect this repo for automatic builds on push
- **Cloudflare Workers:** Add server-side logic or API routes
