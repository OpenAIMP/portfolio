# Portfolio

Personal portfolio website built with HTML, CSS, and modern web standards.

## Project Structure

- `index.html` — Homepage showcasing main focus, system profile, core capabilities, and contact section.
- `styles.css` — Global styling and responsive grid system using modern CSS properties and variables.
- `_redirects` — Path-level HTTP redirect rules (e.g. routing legacy subpage paths `/about/`, `/projects/`, etc. to `/archive/v1/`).
- `_headers` — Custom HTTP response headers for security controls and Content Security Policy (CSP).
- `CNAME` — Custom domain configuration for GitHub Pages deployment.
- `archive/` — Archived versions and multi-page subpage experiments (`archive/v1/`, `archive/v0/`, `archive/portfolio/`).
